# Retail Returns & Liquidation Recovery

Maximize recovery from returned inventory through condition validation, routing, refurbishment, liquidation, and settlement controls.

**Primary buyer:** Retailers and consumer brands. **Evidence:** return policies, RMAs, products, condition grades, carrier events, warehouse receipts, refurbishment, liquidation lots, fees, settlements, and cash.

Full local application built with React, Vite, Express, PostgreSQL, and OpenRouter. Includes 15 domain-specific capabilities, 105 custom AI workbench fields, three scenario-fill controls per feature, operational registers, workflow transitions, analytics, professional AI decision briefs, audit history, and at least 15 PostgreSQL records per capability.

## Domain capabilities

- Return policy library
- RMA ingestion
- Carrier event tracking
- Warehouse receipt matching
- Condition grade validation
- Restock eligibility
- Refurbishment economics
- Liquidation lot creation
- Expected resale value
- Channel fee audit
- Missing unit detection
- Liquidator statement reconciliation
- Dispute workflow
- Cash recovery tracking
- Product disposition analytics
